Запуск тестов
Установите любое IDE для разработки: Jetbrains GoLand (Платное или по студенческой лицензии), VS Code (бесплатное).

Установите Git на компьютер

Установите Go версии 1.25.1

Настройте доступ к своему Github-аккаунту по SSH-ключу.

Склонируйте себе репозиторий: git clone <путь к вашему репозиторию>

Подтяните необходимые зависимости через команду в корне проекта:

go mod tidy

В файле .env.override (создайте его в корне, если нет) выставьте правильные значения для переменных окружения:

TEST_LOGIN=sfme2013@ya.ru
TEST_PASSWORD=906307Zz
TEST_LOGIN_2=elenkainst@ya.ru
TEST_PASSWORD_2=123456Adm
API_URL=https://testboard.avito.com/api/v1

Для запуска всех тестов достаточно выполнить команду в корне проекта:

go test -v ./...

Отдельный пакет с тестами можно запустить командой:

go test -v ./tests/scenarios/myAdvertisement/

Логирование
Для включения логирования request/response в консоль: выставьте переменную окружения DEBUG=true в .env.override

Запуск линтера
Установить приложение golangci-lint

Запуск линтера (из корня репозитория):

golangci-lint run
